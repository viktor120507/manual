Веб-аутентификация

Сохраняется в этом браузере
На этой странице
ЗаданиеРеализация

¶ Задание

10. На маршрутизаторе ISP настройте web-based аутентификацию:

  • При обращении к сайту web.au-team.irpo клиенту должно быть предложено ввести аутентификационные данные
  • В качестве логина для аутентификации выберите WEBс паролем P@ssw0rd
  • Выберите файл /etc/nginx/.htpasswd в качестве хранилища учётных записей
  • При успешной аутентификации клиент должен перейти на веб сайт.

¶ Реализация

Виртуальная машина ISP

Htpasswd — утилита для работы с файлом паролей, обычно входящая в состав дистрибутива веб-сервера Apache. С её помощью создают файлы паролей, добавляют новые записи или модифицируют существующие.
Файл .htpasswd содержит пароли для доступа к ресурсу. Он состоит из строк, каждая из которых соответствует паре логин/хеш пароля. Логин отделяется от хеша двоеточием.

Устанавливаем htpasswd который входи в пакет httpd-tools

# dnf install httpd-tools

Проверяем, что htpasswd установлен

# htpasswd -h

При помощи утилиты htpasswd создаем пользователя WEB с пароль P@ssw0rd и добавляем информацию о нём в файл /etc/nginx/.htpasswd

# htpasswd –c /etc/nginx/.htpasswd WEB

В конфигурационном файле /etc/nginx/nginx.conf добавляем web-based аутентификацию для доступа к сайту web.au-team.irpo

# nano /etc/nginx/nginx.conf

Дописываем следующие строки

auth_basic "Restricted area";
auth_basic_user_file /etc/nginx/.htpasswd;

Перезапускаем nginx

# systemctl restart nginx
