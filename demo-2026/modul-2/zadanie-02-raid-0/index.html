Дисковый массив RAID 0

Сохраняется в этом браузере
На этой странице
ЗаданиеРеализация

¶ Задание

2. Сконфигурируйте файловое хранилище на сервере HQ-SRV:

  • При помощи двух подключенных к серверу дополнительных дисков размером 1 Гб сконфигурируйте дисковый массив уровня 0
  • Имя устройства – md0, при необходимости конфигурация массива размещается в файле /etc/mdadm.conf
  • Создайте раздел, отформатируйте раздел, в качестве файловой системы используйте ext4
  • Обеспечьте автоматическое монтирование в папку /raid

¶ Реализация

Виртуальная машина HQ-SRV

Создание программного RAID0

Выводим список подключенных дисков и их имена.

# lsblk

Для сборки массива применяем следующую команду

# mdadm --create --verbose /dev/md0 -l 0 -n 2 /dev/sdb /dev/sdc

где:
/dev/md0 — устройство RAID, которое появится после сборки;
-l 0 – уровень RAID;
-n 2 – количество дисков, из которых собирается массив;
/dev/sdb /dev/sdc – сборка выполняется из разделов дисков sdb, sdc, sdd.

Должны увидеть что-то подобное

Вводим команду

# lsblk

и видим информацию о том, что у дисков sdb, sdc, появился раздел md0

Создание файла mdadm.conf

В файле mdadm.conf находится информация о RAID-массивах и компонентах, которые в них входят. Для его создания выполняем следующую команду.

Сохраняем конфигурацию массива

# mdadm --detail --scan --verbose  >> /etc/mdadm.conf

Когда массив создан его необходимо отформатировать и смонтировать в дереве каталогов системы.

Отформатируем раздел в ext4

# mkfs.ext4 /dev/md0

Монтирование в папку /raid

В корне системы создадим директорию /raid

# mkdir /raid

Монтируем к RAID директорию /raid командой

# mount /dev/md0  /raid

Результат проверяем командой

# lsblk -f

Чтобы разделы монтировались при загрузке системы, добавляем запись в fstab

Открываем fstab

# nano /etc/fstab

И добавляем строки

/dev/md0    /raid    ext4    defaults    0    0

Проверяем примонтированные разделы

# df -h
