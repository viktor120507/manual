# Секретная перемена

Локальная шуточная игровая комната. Денег, покупок, обмена и настоящих призов нет. Сервер не нужен: банк, коллекция и последние 12 игр сохраняются в `localStorage` под отдельным ключом `pgk-secret-break-v1`.

Вход: кнопка с игральной костью в нижней части бокового / бургер-меню, справа от имени и ника автора. Назад ведёт ссылка на страницу, с которой посетитель пришёл. Лобби: `/peremena/`.

Отдельные страницы: `/peremena/ruletka/`, `/peremena/tri-zacheta/`, `/peremena/kollekciya/`, `/peremena/istoriya/`. На странице игры находится только выбранная игра; общий банк и коллекция сохраняются между страницами.

Любой выигрыш открывает нативный `<dialog>` с предметом, редкостью, выплатой и кнопкой «Забрать приз». Он не закрывается по таймеру; доступны Escape, крестик и переход в коллекцию. Фокус остаётся внутри окна.

- Рулетка: европейский порядок 0–36; чёт/нечет, цвета и половины ×2 (на нуле проигрывают); любое точное число 0–36 ×36.
- Автомат: два одинаковых ×2, три одинаковых ×10, три семёрки ×25.
- Выплата включает ставку. Любой выигрыш добавляет виртуальный предмет; дубликаты учитываются.
- 1 000 стартовых фишек; бесплатная кнопка +500 без покупок.
- Звук включается только по желанию. При уменьшении движения колесо и барабаны не вращаются.
- Завершённый результат сохраняется до анимации, поэтому обновление страницы не теряет выигрыш. Кнопки блокируются до окончания текущей игры.

Призы и их описания находятся в `assets/casino-engine.js`, массив `prizes`. У предмета есть постоянный `id`, `icon`, `name`, `note`, `rarity` (`common`, `rare`, `legendary`) и `weight`. Вес всех предметов должен в сумме равняться 100. Старые `id` нужно сохранять, чтобы не потерять коллекцию; счётчик витрины обновляется автоматически.

Проверка игровой логики: `node --test tests/casino-engine.test.cjs`.
