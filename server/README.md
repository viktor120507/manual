# Чат практикума — локальный предпросмотр

**Обновление:** сервис Cloudflare размещён на Workers Free. Реализация, адрес, ограничения и шаги подключения — в [cloudflare/README.md](cloudflare/README.md). Текущий `assets/chat-config.js` подключает виджет к размещённому сервису. Сайт публикуется на GitHub Pages из ветки `main`. Ниже описан исходный Node.js-прототип, который также продолжает обслуживать локальные страницы на 8780.

Ничего не опубликовано. GitHub Pages обслуживает статические файлы; общий чат требует отдельно запущенного процесса Node.js. Для тестирования процесс обслуживает и сайт, и API.

## Запуск

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
node server/chat-server.mjs
```

Открыть http://127.0.0.1:8780/ в двух вкладках или разных браузерах. На старом локальном предпросмотре с портом 8776 чат также подключается к API на 8780. Каждый браузер получает имя гостя; имя можно изменить. Регистрация, пароль и аккаунт не требуются. Онлайн учитывает посетителей с установленным соединением, даже если окно чата закрыто. Несколько вкладок одной анонимной сессии считаются одним посетителем.

## Хранение и очистка

- Сообщения хранятся только в RAM, без базы данных и без записи истории на диск.
- Вся история очищается каждые 2 часа с момента запуска сервера, затем каждые следующие 2 часа. Очистка проверяется таймером каждые 15 секунд и перед каждым запросом. Посетители видят время до следующей очистки.
- Максимум 200 сообщений; при переполнении старые удаляются сразу. Длина сообщения — до 800 символов, запроса — до 4 КБ.
- Перезапуск процесса также удаляет историю. Сервер не сохраняет логи текста сообщений.
- До 60 соединений, до 20 с одного IP (позволяет одной учебной группе использовать общую сеть); до 500 анонимных сессий. Неактивные сессии удаляются через 30 минут после отключения.
- Ограничения: 8 сообщений за 10 секунд от одного участника, 60 за 10 секунд с IP и 120 за минуту на весь чат. Временные счётчики очищаются и имеют ограничение по количеству.
- В браузере история отображает максимум 200 сообщений. В sessionStorage сохраняется только анонимная сессия, в localStorage — выбранное имя. История сообщений не записывается в хранилище браузера.

Сообщения выводятся как обычный текст через textContent. HTML, скрипты, изображения и вложения из сообщений не исполняются и не загружаются. Чат общий и открытый всем посетителям; это не личные сообщения.

## Проверка

```sh
node --test server/chat-server.test.mjs
```

Проверяет две одновременные сессии, доставку сообщений, присутствие, смену имени, ограничение истории, защиту от частой отправки, проверку источника запроса, размер сообщений, двухчасовую очистку и переподключение без старой истории. Часы в тесте управляемые: ждать два часа не нужно.

## Перед будущей публикацией

Разместить **один** процесс сервера на выбранном хостинге с HTTPS. Несколько независимых процессов без общего хранилища создадут отдельные чаты; текущий вариант рассчитан на один процесс. GitHub Pages не запускает этот сервер.

Указать точные публичные адреса сайта через ALLOWED_ORIGINS (через запятую), PORT и HOST для сервера. Для API без обслуживания статического сайта использовать SERVE_SITE=0. За обратным прокси оставить потоковую передачу /api/chat/events без буферизации и с временем ожидания более 20 секунд; сервер отправляет heartbeat каждые 15 секунд. Значение X-Forwarded-For специально не принимается от произвольного клиента. Если нужно различать посетителей за прокси, доверенные прокси следует настроить отдельно; в текущем варианте ограничения по IP будут общими для прокси.

В подключении assets/chat.js на **всех** страницах задать data-chat-endpoint="https://адрес-сервера/api/chat". Без этого на публичном домене чат показывает, что сервер ещё не подключён. В локальном режиме адрес определяется автоматически. Развёртывание и смену DNS в этой задаче не выполнять.

Не добавлять архивирование, журналы тел сообщений, дампы RAM или автоматическое восстановление истории, если нужно сохранить гарантированное временное хранение. Очистка истории на сервере не удаляет скриншоты, текст, который кто-то уже скопировал, или данные во вкладке, которая полностью зависла; при возвращении/переподключении актуальная история заменяет старую.
